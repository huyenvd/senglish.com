Mẫu file Excel nhập từ vựng

Tải file mẫu, điền từ của bạn rồi vào app chọn Quản lý từ vựng → Chọn tệp Excel để nhập hàng loạt.

📄

Mẫu 2 cột (đơn giản)

Cột A = từ ngoại ngữ, Cột B = nghĩa tiếng Việt.
Phù hợp khi cần nhập nhanh.

⇩ Tải mẫu 2 cột (.xlsx)
📊

Mẫu 4 cột (đầy đủ)

Cột A = từ, B = từ loại (n/v/adj…), C = nghĩa, D = phiên âm.
Khuyên dùng để đủ thông tin.

⇩ Tải mẫu 4 cột (.xlsx)
Lưu ý: hàng đầu tiên là tiêu đề (có chữ “word”) nên app sẽ tự bỏ qua. Bỏ trống nghĩa thì dòng đó bị bỏ qua. Từ loại viết “n”, “danh từ”, “noun”… đều được app tự nhận dạng.
